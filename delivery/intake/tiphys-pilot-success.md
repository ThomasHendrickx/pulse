# What a successful Tiphys pilot looks like

Pulse is also the first real charter on @tiphys/kernel 0.1.0. The run is an
experiment, so its outcome is measured, not felt. Three measures, recorded in
delivery/evidence/ as they happen:

1. **Owner interventions per phase**, split by kind: decision records the
   charter forced (good, the contract working) versus corrections of agent
   output the gates should have caught (bad, a gate gap). Target: zero of the
   second kind after slice 2.
2. **Gate honesty**: defects found in clean-room review or by the owner that
   a declared gate claimed to cover. Each one becomes a tuition entry. Target:
   every escaped defect maps to a named gate improvement, none repeat.
3. **Cost and wall-clock per slice**, from work history. No target, this is
   baseline data for the fleet scale-up decision.

The pilot is a success if the golden journey passes on a real month of the
owner's own exports, and the tuition directory afterwards describes kernel
improvements rather than domain misunderstandings.
